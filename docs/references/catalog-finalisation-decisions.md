# Décisions de finalisation du catalogue

## Activations maintenues

Les associations déjà publiées restent inchangées : Mathématiques et Philosophie pour les huit profils ; Physique-Chimie, SVT et Anglais pour Première/Terminale C et D.

## Nouvelle activation documentée

Le PDF DPFC de français du second cycle mentionne explicitement les classes de Premières C et D ainsi que les Terminales C et D. Le catalogue publie donc Français pour ces quatre couples, avec un `display_order` de 60. Aucun chapitre ni leçon n’est ajouté ; ces matières afficheront leur état vide réel côté élève.

## Exclusions prudentes

Français A1/A2, Anglais A1/A2, Physique-Chimie A1/A2 et SVT A1/A2 restent non publiés : les documents disponibles emploient un groupe A non ventilé entre A1 et A2. Espagnol, Allemand, Histoire-Géographie, Informatique/TICE, Arts plastiques, Éducation musicale, EDHC et EPS restent également non publiés faute d’association explicite exploitable dans les sources consultées.

La matière de test inactive existante reste non publiée et donc invisible côté élève. Le contenu de test Philosophie Terminale A1 n’est pas modifié.
