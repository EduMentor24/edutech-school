# Convention de rédaction — Langues vivantes

## Principe obligatoire

Pour tout nouveau contenu pédagogique de langue vivante créé dans EduTech School, chaque élément présenté dans la langue étudiée est suivi immédiatement de sa traduction française. Cette règle s’applique aux explications, définitions, exemples, consignes, tableaux, questions d’exercice, choix de réponses, corrigés et questions de quiz.

## Format de lecture

Le contenu conserve d’abord la formulation dans la langue étudiée, puis affiche directement sous celle-ci un bloc distinct :

> **Traduction française :** formulation française fidèle.

Les titres de sections peuvent être bilingues lorsque cela favorise le repérage. Les mots-outils, expressions isolées et termes de vocabulaire sont également traduits à leur première apparition. Une traduction ne remplace jamais le texte dans la langue vivante ; elle l’accompagne afin de soutenir la compréhension progressive des élèves.

## Portée

Cette convention s’applique dès le lot Espagnol Terminale en cours et constitue la référence de rédaction pour les futures leçons de langues vivantes. Elle ne modifie pas rétroactivement les contenus publiés existants sans une demande explicite de révision.
